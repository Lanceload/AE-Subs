# AE Subs

Автоматические субтитры для Adobe After Effects (Windows).

Программа распознаёт речь из композиции After Effects или из видео/аудиофайла (Whisper),
даёт отредактировать текст и тайминг, настроить стиль и вставляет субтитры в проект AE
отдельной композицией поверх ваших слоёв.

## Возможности

- Распознавание речи: faster-whisper (large-v3-turbo и другие модели), видеокарта NVIDIA или процессор.
- Звук берётся прямо из открытой композиции AE; можно убрать музыку (отделение голоса, Kim Vocal 2).
- Редактор: список, таймлайн с волной звука, разделение/склейка, авто-тайминг, проверка ошибок.
- Стиль: шрифт, заливка и градиент, две обводки, свечение, тень, плашка, позиция,
  эффекты появления и исчезновения, подсветка слов.
- Свой стиль у отдельного субтитра и у отдельных слов.
- Галерея пресетов, обмен стилями кодом/файлом/через облачную папку.
- Перевод (Google), экспорт в SRT, VTT, ASS, TXT, JSON.
- Двусторонняя синхронизация с AE, отмена/повтор, автосохранение по композициям.
- Горячие клавиши в стиле After Effects и Premiere Pro.
- Обновление прямо из программы: «Справка → Проверить обновления».
- Обратная связь из программы: «Справка → Обратная связь» — ошибка, предложение или отзыв.

## Установка

Скачайте установщик `AE_Subs_Setup_X.Y.Z.exe` со страницы [Releases](https://github.com/Lanceload/AE-Subs/releases)
или с зеркала [Hugging Face](https://huggingface.co/Yaqen/AE-Subs/tree/main), если GitHub качает медленно.
Во время установки можно сразу скачать модель распознавания (1,6 ГБ), ускорение на видеокарте NVIDIA
(CUDA, 2 ГБ) и отделение голоса от музыки (67 МБ) — или позже, программа докачает нужное сама.

Без установки: архив `AE_Subs_X.Y.Z.zip` — распаковать в любую папку и запустить `AE Subs.exe`.

Нужен After Effects (проверено на AE 2025). Программа запускает скрипты через `AfterFX.exe -r`.

## Запуск из исходников

```bat
pip install -r requirements.txt
python main.py
```

Сборка exe: `build.bat` (PyInstaller) → папка `AE Subs`.
Архив для релиза: `python tools\make_release.py` → `release\AE_Subs_X.Y.Z.zip`.
Установщик: `python tools\make_installer.py` (Inno Setup 6.5+) → `release\AE_Subs_Setup_X.Y.Z.exe`.
Версия задаётся в `app/version.py`, релиз публикуется с тегом `vX.Y.Z`; тот же архив
загружается в https://huggingface.co/Yaqen/AE-Subs — программа качает обновления сначала оттуда.

## Обратная связь

Сообщения из окна «Обратная связь» уходят на сервер-посредник (`feedback-worker`, Cloudflare Workers),
а он пересылает их разработчику в Telegram. Токен бота хранится только в секретах Cloudflare,
в программе и в репозитории его нет. Ограничения: 3 сообщения в минуту с одного адреса и 300 в сутки всего.

Выложить сервер: `cd feedback-worker`, `npm install`, `npx wrangler deploy`;
секреты `TG_TOKEN`, `OWNER_CHAT_ID`, `WEBHOOK_SECRET` — через `npx wrangler secret put`.
